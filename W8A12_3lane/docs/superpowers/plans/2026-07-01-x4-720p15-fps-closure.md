# X4 720p15 FPS Closure Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce a contest-report-ready x4 720p15 FPS closure gate from the packed 2-D scheduler simulation.

**Architecture:** Keep the existing Vivado xsim scheduler as the timing source. Add a Python closure checker that reads the xsim `summary.json`, validates 24x64 and 24x72 against 720p output, 900-DSP resource gate, 15fps target, and 24x72 overhead margin, then emits a dedicated closure evidence directory. Update reports and manifests to point at this gate without claiming board-measured FPS.

**Tech Stack:** Python 3, PowerShell, Vivado xsim, Markdown/JSON evidence files.
